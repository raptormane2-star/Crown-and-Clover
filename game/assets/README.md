# Local third-party assets

The public repository intentionally does not redistribute raw third-party pixel-art/audio unless the specific license permits source redistribution.

For local development, copy the asset folders from the supplied Crown & Clover project archive into `game/assets/` using the existing paths (`cute`, `farm`, `villagers`, `ruins`, `chars`, `icons`). Put prototype audio in `game/audio/`.

The v0.4 runtime uses an AssetCatalog so source validation can still run when licensed art is absent from a public checkout.

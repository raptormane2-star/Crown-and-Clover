# Third-Party Asset Tracking

Crown & Clover uses third-party pixel-art packs locally during development. Because this repository is public, raw source art/audio is not committed unless source redistribution is explicitly permitted.

## Packs tracked
- Cute Fantasy Free
- Farm RPG FREE 16x16 - Tiny Asset Pack
- Tiny RPG Character Asset Pack 01
- Minifolks Villagers 2
- Ruined Village Buildings - Pixel Art Assets
- Free - Raven Fantasy Icons
- Mighty Battler

## Confirmed restriction
The supplied MutterPixel Studio / Ruined Village license permits use in games but prohibits standalone distribution of the raw files. Keep the original license with the project and do not publish those sprites in this public source repository.

## Policy
1. Keep raw third-party art/audio local by default.
2. Retain original licenses, source URLs and receipts where applicable.
3. Commit raw assets only when their license explicitly permits source redistribution.
4. Use compiled game distributions according to each pack's terms.
